# ClubMaster Frontend

Frontend application for **ClubMaster**, built with React and Vite.

## Tech Stack

* React
* Vite
* JavaScript
* Axios

## Description

ClubMaster Frontend is the client-side application of the ClubMaster project.

It communicates with the ClubMaster backend through REST APIs and displays data dynamically in the user interface.

## Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm

### Installation

Clone the repository and install the dependencies:

```bash
npm install
```

### Run the application

Start the development server:

```bash
npm run dev
```

The application will be available at:

`http://localhost:5173`

## Backend

The frontend communicates with the ClubMaster backend, which runs locally on:

`http://localhost:8080`
